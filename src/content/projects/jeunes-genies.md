## Context

Jeunes Génies was an after-school program for students aged 12 to 16. I created and ran weekly sessions for one year, using Python and robotics projects to teach programming through physical results.

## My responsibility

I designed the curriculum, taught the sessions, prepared the hardware, helped students debug their projects, and built the program website.

## Program design

### Project-based lessons

Each lesson paired a programming concept with a working build. Students read sensors, controlled motors, wrote conditions and loops, and tested how code changed a robot’s behaviour.

### Mixed experience levels

Exercises had a clear base objective and optional extensions. Beginners could complete a working project while more experienced students added controls, sensors, or different behaviour.

### Program website

The site introduced the courses, published events and updates, and gave parents a place to review the program and enrollment information.

## Result

The program ran weekly for a full year. Students gained practical experience writing Python, wiring components, testing control logic, and debugging their own work.
